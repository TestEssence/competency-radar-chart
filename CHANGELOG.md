# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-06

### Added

- Initial public release.
- `renderChart`, `renderSvg`, `renderToFile`, `toHtml`, `toPng`, `normalize`,
  `loadConfig` Node API.
- `competency-radar` CLI with `render` and `init` commands, orientation / size / title /
  profile overrides, and SVG / PNG / HTML output.
- Configurable levels, category bands and wedges, overlaid profiles, colour scheme and
  layout.
- Bundled examples: `test-roles.json`, `engineering-competencies.json`.
